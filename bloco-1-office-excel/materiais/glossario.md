# Glossario Basico

## Arquivo

Item salvo no computador, como um documento, imagem, planilha ou apresentacao.

## Pasta

Local usado para organizar arquivos.

## Word

Programa usado para criar e editar documentos de texto.

## Excel

Programa usado para criar planilhas, tabelas, formulas e graficos.

## PowerPoint

Programa usado para criar apresentacoes em slides.

## PDF

Formato de arquivo muito usado para enviar documentos sem alterar a formatacao.

## Celula

Espaco da planilha onde digitamos dados no Excel.

## Formula

Instrucao usada no Excel para calcular valores. Normalmente comeca com `=`.

## Grafico

Representacao visual de dados.

## Atalho

Combinacao de teclas usada para executar uma acao rapidamente.
