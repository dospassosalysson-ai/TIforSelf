# Aula 07 - Excel: Tabelas, Filtros e Classificacao

## Objetivos

- Organizar dados em formato de tabela.
- Usar filtros.
- Classificar informacoes.

## Conteudo

- Cabecalho de tabela.
- Formatar como tabela.
- Filtros.
- Classificacao alfabetica.
- Classificacao por valores.
- Boas praticas para listas.

## Pratica guiada

Criar uma planilha de clientes ficticios com:

- Nome
- Cidade
- Telefone
- Produto de interesse
- Valor estimado

## Atividade

Usar filtros para responder:

- Quais clientes sao de uma cidade especifica?
- Qual e o maior valor estimado?
- Quais produtos aparecem com mais frequencia?

## Fechamento

Mostrar que filtros ajudam a encontrar informacoes rapidamente sem apagar dados.
