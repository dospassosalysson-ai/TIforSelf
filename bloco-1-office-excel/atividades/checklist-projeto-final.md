# Checklist do Projeto Final

Tema: **Meu planejamento mensal**

## Organizacao

- [ ] Criei uma pasta chamada `Projeto Final`.
- [ ] Salvei todos os arquivos dentro da pasta correta.
- [ ] Usei nomes claros nos arquivos.
- [ ] Testei se todos os arquivos abrem.

## Word

- [ ] O documento tem titulo.
- [ ] O texto explica o planejamento mensal.
- [ ] O documento esta bem formatado.
- [ ] Usei lista ou tabela.
- [ ] Revisei erros de digitacao.

## Excel

- [ ] A planilha tem cabecalhos claros.
- [ ] Usei valores numericos.
- [ ] Usei pelo menos uma formula.
- [ ] Calculei total ou media.
- [ ] Criei pelo menos um grafico.

## PowerPoint

- [ ] A apresentacao tem de 5 a 7 slides.
- [ ] O primeiro slide tem titulo.
- [ ] Os slides estao legiveis.
- [ ] Usei imagem ou grafico.
- [ ] Testei em modo apresentacao.

## PDF

- [ ] Salvei pelo menos um arquivo em PDF.
- [ ] Abri o PDF para conferir.

## Apresentacao

- [ ] Consigo explicar o projeto em 2 a 3 minutos.
- [ ] Sei mostrar a planilha e explicar os calculos.
- [ ] Sei explicar o grafico.
